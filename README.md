# Portfolio Website Upload

Statisches Upload-Paket fuer GitHub und Hosting.

## Inhalt

- Nur verwendete Website-Dateien und Assets
- Keine tmp-, Undo- oder macOS-Dateien
- Dateinamen/Pfade ASCII-sicher ohne Leerzeichen
- Bilder weboptimiert, grosse Videos auf kleinere MP4-Fallbacks reduziert/komprimiert

`index.html` ist die Startseite.
